# SimpleAuction

Аукцион `/ah` для Paper 1.21.x (нужен Vault + плагин экономики).

## Сборка
Локально: `gradle build` → `build/libs/SimpleAuction-<версия>.jar`.

На GitHub: каждый push собирает jar (Actions → Build → Artifacts).
Релиз: `git tag v1.0.0 && git push origin v1.0.0` — jar появится в Releases.
